# Noto CJK fallback

Unmodified Noto Sans CJK SC Bold from the official Sans2.004 release.

- Source: https://github.com/notofonts/noto-cjk/tree/523d033d6cb47f4a80c58a35753646f5c3608a78
- Font: https://raw.githubusercontent.com/notofonts/noto-cjk/523d033d6cb47f4a80c58a35753646f5c3608a78/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Bold.otf

- License: SIL OFL 1.1, reproduced unchanged in NotoSansCJK-LICENSE.txt. Copyright/name metadata remains in the unmodified font.

The bundled CJK font supplies missing Hangul, kana and common simplified/traditional Han glyphs independently of optional Windows language fonts. The UI selects a font per Unicode code point, groups adjacent runs, and aligns baselines. Installed Segoe UI Emoji and SimSun extension fonts supplement symbols and uncommon Han where present; these system fonts are not redistributed. This is font coverage, not a guarantee that every Unicode character exists in the included font.
