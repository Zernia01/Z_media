# ZM 0.1.0 검증 기록

검증 날짜: 2026-10-06 (한국 시간). Windows x64, MSVC 19.51, FFmpeg n9.0.2-22, SDL2 2.32.10, SDL2_ttf 2.24.0.

## 수행한 검증

- Release와 Debug 빌드 및 CTest 통과. /W4의 컴파일 경고 없이 빌드.
- 최종 CTest 결과는 각 구성에서 3/3 통과: 코어, H.264/AAC 실제 재생 회귀, 다중 오디오 MKV 회귀. GPU 사용과 하드웨어 비활성화 후 소프트웨어 재생을 각각 검사했습니다.
- FFmpeg로 생성한 H.264/AAC MP4, HEVC/AAC MKV, AV1/Opus MKV, VP9/Opus WebM: UI smoke 종료 코드 0.
- 3840×2160 HEVC: UI smoke 종료 코드 0. 화면에서 실제 GPU 디코딩 표시 확인.
- 한글/일본어/중국어/Emoji 혼합 파일명: UI smoke 종료 코드 0.
- 외부 한글 SRT와 MKV 내장 텍스트 자막: 재생 성공. 외부 SRT의 실제 영상 합성 화면 확인.
- 서로 다른 AAC 오디오 트랙 2개를 포함한 MKV: 트랙 전환 회귀 테스트 통과.
- 일시정지 시 clock 고정, seek 후 재생 복구, 연속 seek 20회, 파일 교체 15회, 자막 ON/OFF, EOF 완료 상태: 회귀 테스트 통과.
- 단축키 충돌 감지/교체/개별 복원, 재생목록 이동/제거/전체 반복: 코어 테스트 통과.
- 빈 파일 및 손상된 MP4: 오류를 유지하며 창이 실행됨. smoke 종료 코드 2는 정상적인 오류 검출 결과.
- 다크 단축키 설정창과 라이트 자막 설정창의 화면 캡처를 검사해 배치/대비 확인. 한국어 환영 화면과 실제 재생 화면도 검사.

- 영상 영역과 시간/탐색/재생 버튼 영역을 공통 레이아웃으로 분리했습니다. 760×480 창에서 한국어/영어 재생 화면과 재생목록 배치를 캡처해 겹침 여부를 검사했습니다.
- 사이드바 설정창의 일반/자막 화면, 작은 창의 스크롤, 언어 선택 목록 및 라이트 모양 화면을 캡처해 확인했습니다.
- 나눔스퀘어라운드 폰트와 라이선스를 번들에 포함했습니다. 중국어 선택 항목의 글리프 대체도 화면으로 확인했습니다.
- 사용자 제공 icon.png를 16~256px ICO로 변환해 실행 파일에 포함하고 창 아이콘에 연결했습니다. 실행 파일에서 추출한 아이콘으로 원본 적용을 확인했습니다.
- 변경 후 Release와 Debug의 CTest는 각각 3/3 통과했습니다.
- 일본어/중국어 UI에서 한글 대체 글꼴이 현재 언어 글꼴로 다시 선택되는 오류를 수정했습니다. 일본어·중국어 간체·번체의 언어 목록을 각각 캡처하여 한국어 및 국한문혼용체 항목이 정상 표시되는 것을 확인했습니다.

- Release/Debug 빌드와 CTest 각각 4/4 통과. 탐색/볼륨 드래그 및 폴더 클릭 UI 회귀 검사도 통과했습니다.
- Windows 이동 진입/종료 메시지와 네이티브 메시지 루프를 사용하여 일반 SDL 프레임 루프를 멈춘 동안의 갱신을 검사했습니다. 계속 표시 ON은 새 영상 프레임 출력, OFF는 출력 없음으로 확인했습니다. 타이머 렌더링은 UI 스레드에서 수행하고 재진입을 차단합니다.
- 전체화면에서 숨김 ON/OFF 화면을 캡처해 확인했습니다. 일시정지 중에도 상·하단 UI와 폴더 목록이 숨겨지는 것을 확인했습니다.
- 모양 설정의 두 체크박스 및 정보 설정의 Buy Me a Coffee 버튼을 캡처해 확인했습니다. 후원 버튼은 지정 URL을 기본 브라우저에서 열며 결제는 수행하지 않습니다.

## 장거리 탐색 지연 개선 검증

- 일반 탐색에서 로드한 자막 이벤트와 글꼴을 재사용합니다. 자막 파일·트랙·설정·영상 크기가 바뀌면 기존처럼 다시 생성합니다. 탐색은 요청 위치 이전 키프레임부터 디코딩합니다.
- 탐색바는 모든 마우스 이동을 즉시 표시하고, 드래그 중 디코더 요청은 최대 초당 10회로 제한합니다. 버튼을 놓은 최종 위치는 즉시 반영합니다. 기존 드래그 smoke 검사가 통과했습니다.
- `scripts/create-seek-fixture.ps1`로 12분 H.264/AAC 및 내장 다국어 텍스트 자막 영상을 생성했습니다. 70→600→70→603.3→615→70초 이동의 첫 프레임 위치, 실제 자막 픽셀, 역방향 탐색과 새 필터의 결과 일치, 무자막 구간 및 재생/오디오 복구를 검사했습니다. Release/Debug CTest 각각 5/5 통과했습니다.
- 로컬 320×180 합성 영상/소프트웨어 디코딩에서 600초 탐색의 첫 프레임 대기 시간은 변경 전 26ms, 변경 후 5ms였습니다. 전체 측정 구간은 변경 전 20~32ms, 변경 후 3~10ms입니다. 단일 로컬 측정이며 실제 작품의 해상도·키프레임 간격·컨테이너 인덱스·디스크에 따른 지연을 보장하지 않습니다.
- FFmpeg 자막 필터가 프레임 타임스탬프로 libass를 호출하는 구현을 확인했습니다: https://www.ffmpeg.org/doxygen/9.0/vf__subtitles_8c_source.html

## 재생 중 영상·오디오 끊김 개선 검증

- 영상 대기열이 가득 찬 동안 이미 재생 시각보다 80ms 이상 늦은 프레임을 정리하여 같은 작업 스레드의 오디오 디코딩이 계속되도록 했습니다. 일시정지·탐색 미리보기와 미래 프레임은 유지합니다. 100ms 이상 늦은 출력 프레임의 변환/자막 합성도 생략하며 코덱의 참조 프레임 디코딩은 계속합니다.
- 한 번의 화면 갱신에 실제로 표시할 최신 프레임만 GPU에 업로드합니다. YUV420P 소프트웨어 디코딩 출력은 불필요한 전체 프레임 복사 대신 참조를 유지하고, 자막 필터의 쓰기 가능한 버퍼 처리를 사용합니다. 소프트웨어 디코딩은 CPU 수에 따라 최대 8개 스레드를 사용합니다.
- Vsync 대기 이후의 고정 5ms 지연을 제거하고 빠른 렌더러에만 최소 대기를 적용했습니다. 오디오 장치의 일시정지 상태 변경도 필요한 경우에만 호출합니다.
- `scripts/create-smoothness-fixture.ps1`로 생성한 1080p/60fps H.264/AAC 영상에서 화면 소비를 450ms 중단했습니다. 변경 전 오디오 대기열 고갈 1회(테스트 종료 2)를 재현했고 변경 후 0회(종료 0)를 확인했습니다. SDL dummy 오디오 장치를 사용한 로컬 회귀 검사이며 모든 실제 장치/작품의 끊김 해결을 보장하지 않습니다.
- Release/Debug CTest 각각 6/6 통과. 1080p/60fps, 4K HEVC, AV1, VP9 재생 smoke와 탐색 드래그, 네이티브 창 이동, 전체화면 숨김 smoke가 모두 종료 코드 0입니다.
- 프레임 참조 API 확인: https://ffmpeg.org/doxygen/9.0/group__lavu__frame.html

## 설정 선택 목록 위치 수정 검증

- 테마 메뉴가 언어 메뉴의 고정 좌표를 사용하던 문제를 수정했습니다. 언어·테마·하드웨어 선택 목록은 실제 선택 버튼의 위치와 너비를 공통으로 사용하며 스크롤 위치도 반영합니다. 아래 공간이 부족하면 버튼 바로 위로 전환합니다.
- 다크·라이트 1120×720 화면과 스크롤한 760×480 화면을 캡처해 테마 버튼과 목록 사이 6px 간격을 확인했습니다. Release CTest 6/6 통과했습니다.

## 아이콘 UI 개선 검증

- 파일 열기, 재생/일시정지, 5초 이동, 정지, 음소거, 전체화면, 폴더 목록, 설정과 목록의 이전/다음·반복·무작위 버튼을 아이콘으로 표시합니다. 설정 사이드바도 아이콘으로 표시하며 폭을 84px로 줄였습니다. 페이지 제목과 설정 설명은 유지합니다.
- 아이콘은 SDL 도형으로 직접 그려 글꼴의 이모지 지원 여부와 관계없이 표시합니다. 아이콘 버튼과 설정 메뉴에 400ms 마우스 hover 후 기존 언어의 기능 이름을 표시하는 툴팁을 구현했습니다.
- 재생 버튼과 상단 아이콘, 다크·라이트 설정 사이드바 및 760×480 창의 테마 메뉴 화면을 캡처해 배치를 확인했습니다. 드래그/볼륨 UI smoke 종료 코드 0, Release CTest 6/6 통과했습니다.

## 첫 클릭 인식 개선

- 초기화 전에 `SDL_HINT_MOUSE_FOCUS_CLICKTHROUGH=1`을 설정해 포커스 없는 창을 활성화하는 첫 클릭도 버튼 이벤트로 전달합니다. SDL 기본 동작은 활성화 클릭을 무시합니다: https://wiki.libsdl.org/SDL2/SDL_HINT_MOUSE_FOCUS_CLICKTHROUGH
- 설정 선택 목록 밖의 다른 메뉴/컨트롤을 클릭하면 목록 닫기와 해당 동작을 같은 클릭에서 처리합니다. 선택 목록 내부의 항목 클릭은 선택 후 종료하며, 자체 선택 버튼을 다시 누르면 닫기만 수행합니다.
- 최종 Release 빌드와 기존 CTest 6/6 통과. 실제 다른 앱에서 전환하는 마우스 입력은 자동화로 검증하지 않았습니다.

## GitHub 업데이트 기능 검증

- 시작 시 확인·새 설치기 자동 다운로드 옵션을 일반 설정에 추가하고 정보 화면에도 수동 확인·다운로드·설치 버튼을 연결했습니다. 백그라운드 스레드에서 HTTPS로 릴리스 메타데이터와 설치기를 읽습니다. 설치 버튼은 다운로드 및 SHA-256 검증 완료 후 활성화되며, 실행 직전에 파일을 다시 검증합니다.
- 엄격한 안정 버전 비교, 중복/잘못된 JSON 필드, 다른 저장소 URL, 잘못된 해시와 변조된 파일 거부 검사를 추가했습니다. Release/Debug 각각 CTest 7/7 통과했습니다. 일반·정보 화면을 캡처해 옵션과 버튼을 확인했습니다.
- 캡처 시 SDL_RenderPresent 이후 백버퍼가 유효하다고 가정하던 검증 도구도 수정했습니다. 캡처 전 화면을 다시 그려 픽셀을 읽습니다.
- GitHub 공개 릴리스와 실제 다운로드 검사는 게시 후 별도로 기록합니다.

## 검증 범위의 한계

테스트 영상은 합성 영상이며 12분 영상의 장거리 탐색을 추가로 검사했습니다. 장시간 A/V drift와 실제 작품 전체를 검증하지 않았습니다. 8K/4K AV1, 메모리 누수/경쟁 조건의 sanitizer 검사, 매우 긴 경로, 여러 GPU/출력 장치, 하드웨어 장치 실패를 강제로 주입하는 시험, ASS/SSA/WebVTT의 복잡한 스타일과 비트맵 자막은 아직 검증하지 않았습니다. 테스트 통과가 작업지시서 전체 완료를 뜻하지 않습니다.
