ZM 0.1.4는 영상 위치 이동 시 화면 깜빡임을 수정한 버전입니다.

- 탐색 중 현재 영상 프레임을 유지하고 새 위치의 첫 프레임이 준비되면 바로 교체합니다. 일시정지 중 위치 이동에도 적용됩니다.
- 영상 파일을 오디오 전용 파일로 잘못 판단해 ‘오디오 재생 중’ 화면을 표시하던 문제를 수정했습니다.
- 다른 파일을 열거나 같은 파일을 다시 열 때는 이전 영상 화면을 정상적으로 초기화합니다.
- 기존 다국어 글꼴과 자동 업데이트·설치 알림 설정을 유지합니다.

설치형: `ZM-0.1.4-setup-win64.exe`를 다운로드해 실행하세요.
포터블: `ZM-0.1.4-win64.zip`을 압축 해제하고 ZM.exe를 실행하세요.
업데이트 정보: `update.json`, 무결성 확인: `SHA256SUMS.txt`.
