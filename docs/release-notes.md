ZM 0.1.1은 UI 글꼴의 굵기와 가독성을 개선한 버전입니다.

- 기본 UI 글꼴을 나눔스퀘어라운드 Bold로 변경했습니다. 설정 설명·선택 목록·재생 정보에도 굵은 글꼴을 적용했습니다.
- 설정 제목과 환영 화면 제목을 28px Bold로 키웠습니다.
- 일본어·중국어 및 한글 대체 글꼴도 각 언어의 Bold 글꼴을 사용합니다.
- 프로그램·실행 파일·설치기 버전을 0.1.1로 통일했습니다.
- 0.1.0의 자동 업데이트에서 새 설치기를 다운로드하고 설치 버튼으로 적용할 수 있습니다.

설치형: `ZM-0.1.1-setup-win64.exe`를 다운로드해 실행하세요.
포터블: `ZM-0.1.1-win64.zip`을 압축 해제하고 ZM.exe를 실행하세요.
업데이트 정보: `update.json`, 무결성 확인: `SHA256SUMS.txt`.
