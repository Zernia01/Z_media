ZM 0.1.8은 30fps 영상의 표시 간격과 오디오 선행 읽기를 개선한 버전입니다.

- 오디오 장치가 버퍼를 묶음으로 소비할 때 계단처럼 움직이던 재생 시계를 보간해 프레임 표시 간격의 흔들림을 줄였습니다. 오디오 시계에 계속 맞추며 탐색·파일 변경 시 보간 상태를 초기화합니다.
- 영상 데이터가 먼저 모여 있는 MP4에서 영상 대기 중에도 뒤쪽 오디오를 읽도록 개선했습니다. 압축된 영상 패킷은 크기·개수를 제한해 보관하고 탐색·종료 시 해제합니다.
- 사용자 제공 720p/30fps H.264/AAC 파일의 완성된 복사본으로 CPU·GPU 재생과 연속 재생을 확인했습니다.
- 자막 전환·장거리 탐색·4K·고프레임률·기존 창 열기를 포함한 Release 테스트 17개가 통과했습니다.

설치형: `ZM-0.1.8-setup-win64.exe`를 다운로드해 실행하세요.
포터블: `ZM-0.1.8-win64.zip`을 압축 해제하고 ZM.exe를 실행하세요.
업데이트 정보: `update.json`, 무결성 확인: `SHA256SUMS.txt`.
