ZM 0.1.2는 업데이트 설치 확인 알림을 추가한 버전입니다.

- 새 업데이트가 준비되면 “최신 업데이트가 있습니다. 설치하시겠습니까?” 창을 표시합니다.
- 일반 설정의 “업데이트 설치 알림 표시”에서 ON/OFF할 수 있습니다. 기본값은 ON이며 저장됩니다.
- “설치”를 누르면 검증한 설치기를 실행하고 플레이어를 종료합니다. “나중에”를 누르면 현재 실행 중 같은 버전의 알림을 반복하지 않습니다.
- 자동 다운로드가 OFF이면 알림에서 “설치”를 선택한 후 다운로드·검증하고 승인한 버전만 설치합니다.
- 알림을 끈 상태에서도 설정의 수동 확인·다운로드·설치 버튼은 사용할 수 있습니다.
- 확인창을 표시할 때 재생 중인 영상은 잠시 일시정지하고, 설치하지 않고 돌아오면 재생을 이어갑니다.

설치형: `ZM-0.1.2-setup-win64.exe`를 다운로드해 실행하세요.
포터블: `ZM-0.1.2-win64.zip`을 압축 해제하고 ZM.exe를 실행하세요.
업데이트 정보: `update.json`, 무결성 확인: `SHA256SUMS.txt`.
