ZM 0.1.7은 간헐적인 영상·소리 끊김을 줄이기 위한 재생 최적화 버전입니다.

- 오디오 버퍼가 부족할 때 영상 대기열의 이미 표시 시각이 지난 프레임을 정리하여 오디오 공급 대기를 줄였습니다. 미래 프레임과 일시정지·탐색 미리보기는 유지합니다.
- 오디오 변환 버퍼를 재사용해 반복적인 메모리 할당을 줄였습니다.
- 지원되는 GPU·렌더러에서 자막 합성이 필요 없는 NV12 영상을 직접 업로드하여 CPU 색상 변환을 줄였습니다. 자막을 켜거나 지원되지 않는 경우 기존 YUV 경로를 사용합니다.
- 1080p/60fps·고프레임률·4K 스트레스 재생과 자막 전환, 탐색 및 기존 창 미디어 열기 검사를 통과했습니다.

설치형: `ZM-0.1.7-setup-win64.exe`를 다운로드해 실행하세요.
포터블: `ZM-0.1.7-win64.zip`을 압축 해제하고 ZM.exe를 실행하세요.
