ZM 0.1.9는 MKV/FLAC 재생 중 영상이 멈칫하던 문제를 개선한 버전입니다.

- 긴 오디오 묶음으로 버퍼가 찬 동안에도 뒤쪽 영상 패킷을 읽어 영상 디코딩이 멈추지 않도록 했습니다.
- 영상·오디오 각각의 패킷 순서를 보존하고 양방향 선행 읽기의 재귀 진입을 차단합니다. 선행 읽기 메모리 한도와 탐색·종료 시 정리를 유지합니다.
- 실제 1080p 10비트 HEVC + 24비트 FLAC MKV에서 GPU·소프트웨어 재생과 탐색을 검사했습니다.
- 합성 10비트 HEVC/FLAC MKV의 마지막 프레임 및 종료 구간을 포함한 회귀 테스트 17개를 통과했습니다.

설치형: `ZM-0.1.9-setup-win64.exe`를 다운로드해 실행하세요.
포터블: `ZM-0.1.9-win64.zip`을 압축 해제하고 ZM.exe를 실행하세요.
업데이트 정보: `update.json`, 무결성 확인: `SHA256SUMS.txt`.
