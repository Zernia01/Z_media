ZM 0.1.5는 새 프로그램 아이콘을 적용한 버전입니다.

- 사용자 제공 logo.png를 Windows용 다중 크기 아이콘(16~256px)으로 변환했습니다.
- 실행 파일, 창·작업표시줄, 설치기와 바로가기에 새 아이콘을 적용했습니다.
- 탐색 화면 유지, 다국어 표시 및 자동 업데이트·설치 알림 기능을 유지합니다.

설치형: `ZM-0.1.5-setup-win64.exe`를 다운로드해 실행하세요.
포터블: `ZM-0.1.5-win64.zip`을 압축 해제하고 ZM.exe를 실행하세요.
업데이트 정보: `update.json`, 무결성 확인: `SHA256SUMS.txt`.
