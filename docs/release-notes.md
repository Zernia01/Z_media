ZM 0.1.6은 미디어를 열 때 사용할 창을 선택할 수 있는 버전입니다.

- 일반 설정에 ‘다른 미디어를 기존 창에서 열기’를 추가했습니다.
- ON이면 탐색기·연결 프로그램에서 연 미디어를 실행 중인 창에서 재생합니다. OFF이면 새 창을 엽니다. 기본값은 기존 동작인 OFF입니다.
- 선택은 즉시 저장되어 프로그램을 종료하지 않아도 다음 파일부터 적용됩니다.
- 한글·일본어·중국어·이모지 파일명과 상대 경로를 지원하며, 기존 창이 응답하지 않으면 새 창으로 엽니다.
- 실행 중인 창이 여러 개이면 요청을 받을 수 있는 창 하나에서 재생합니다.

설치형: `ZM-0.1.6-setup-win64.exe`를 다운로드해 실행하세요.
포터블: `ZM-0.1.6-win64.zip`을 압축 해제하고 ZM.exe를 실행하세요.
업데이트 정보: `update.json`, 무결성 확인: `SHA256SUMS.txt`.
