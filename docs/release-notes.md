ZM 0.1.0은 Windows 10/11 x64용 Zernia media의 첫 공개 버전입니다.

- FFmpeg 기반 영상·음악 재생과 하드웨어 디코딩, 자막, 다중 오디오 트랙.
- 폴더 영상 목록, 탐색·볼륨 드래그, 전체화면 숨김과 창 이동 중 재생.
- 다크·라이트, 둥근 글꼴, 아이콘 버튼, 6개 언어와 단축키 설정.
- 장거리 탐색과 화면 처리 지연 시 오디오 끊김 개선.
- 시작 시 업데이트 확인 및 새 설치기 자동 다운로드. 일반 설정에서 각각 ON/OFF 가능.
- 지정 GitHub 릴리스 주소와 SHA-256 검증 후 설치 버튼 제공. 설치 버튼을 누르면 플레이어를 종료하고 설치기를 실행합니다.

설치형: `ZM-0.1.0-setup-win64.exe`를 다운로드해 실행하세요.
포터블: `ZM-0.1.0-win64.zip`을 압축 해제하고 ZM.exe를 실행하세요.
업데이트 정보: `update.json`, 무결성 확인: `SHA256SUMS.txt`.

초기 버전입니다. 실제 영상·GPU·오디오 장치에 따라 성능과 지원 범위가 다를 수 있습니다.
