ZM 0.1.3는 중국어·한자 파일명 표시를 개선한 버전입니다.

- 글자가 없는 경우 문자열 전체를 한글 글꼴로 바꾸던 처리를 문자별 글꼴 대체로 변경했습니다.
- Noto CJK Bold와 라이선스를 함께 제공하여 Windows 선택 언어 글꼴이 없어도 주요 중국어·일본어·한글·한자가 표시됩니다.
- 한국어·영어·일본어·간체·번체·국한문 UI 모두에서 혼합 파일명을 확인했습니다.
- 제목·버튼·툴팁의 측정에도 실제 대체 글꼴을 사용하여 크기와 기준선을 맞췄습니다.
- 설치된 Windows 이모지·확장 한자 글꼴도 보조 글꼴로 사용합니다.

설치형: `ZM-0.1.3-setup-win64.exe`를 다운로드해 실행하세요.
포터블: `ZM-0.1.3-win64.zip`을 압축 해제하고 ZM.exe를 실행하세요.
업데이트 정보: `update.json`, 무결성 확인: `SHA256SUMS.txt`.
