# Zernia media

**ZM · 0.1.0 · Windows x64**

[0.1.0 설치기 다운로드](https://github.com/Zernia01/Z_media/releases/download/v0.1.0/ZM-0.1.0-setup-win64.exe) · [포터블 ZIP](https://github.com/Zernia01/Z_media/releases/download/v0.1.0/ZM-0.1.0-win64.zip) · [릴리스](https://github.com/Zernia01/Z_media/releases)

C로 작성한 데스크톱 미디어 플레이어의 초기 버전입니다. FFmpeg 공유 라이브러리를 직접 호출하고 SDL2로 창·영상·오디오를 출력합니다. 전체 작업지시서의 모든 기능이 완성된 버전은 아닙니다.

## 실행

`dist/ZM-0.1.0-win64/ZM.exe`를 실행하세요. DLL과 `i18n`, `fonts` 폴더가 필요하므로 배포 폴더 전체를 함께 이동하거나 ZIP을 압축 해제해 사용하세요. Windows 10/11 x64용이며 Visual C++ x64 런타임 DLL을 함께 제공합니다.

설치형은 `dist/ZM-0.1.0-setup-win64.exe`입니다. 사용자 계정의 `AppData/Local/Programs/Zernia media`에 설치하며, 관리자 권한 없이 시작 메뉴와 선택형 바탕화면 바로가기를 제공합니다. Windows 설치된 앱에서 제거할 수 있습니다.

파일 열기 버튼, Ctrl+O 또는 드래그 앤 드롭으로 미디어를 엽니다. 여러 파일을 선택할 수 있으며, 파일 선택 창은 모든 파일을 표시하므로 확장자만으로 재생을 제한하지 않습니다. 실제 지원 범위는 FFmpeg 디코더에 따릅니다.

## 구현된 기능

- 영상/음악 재생, 일시정지, 정지, 탐색바와 ±5초/±30초 탐색.
- 오디오 기준 동기화, 제한된 프레임/오디오 큐, UI와 분리한 분석/디코딩 작업 스레드.
- 볼륨, 음소거, 전체화면, 더블클릭/휠, 전체화면 컨트롤과 커서 자동 숨김.
- 다중 파일 재생목록, 이전/다음, 자동 다음 파일, 한 파일/전체 반복, 무작위 재생.
- 영상 한 개를 열면 같은 폴더의 비디오를 이름순으로 모으는 폴더 목록. 목록 한 번 클릭으로 재생합니다. 하위 폴더·음악·자막은 자동 목록에서 제외하며 최대 4096개입니다. 여러 파일을 직접 선택하면 기존 재생목록을 사용합니다.
- 탐색바와 볼륨을 누른 채 드래그. 창 밖으로 이동해도 드래그를 유지하며 범위 끝에서 값을 제한합니다.
- 일반 설정의 '폴더 목록 자동 열기' ON/OFF. 기본값은 ON이며, OFF에서는 영상을 열어도 목록 패널을 자동으로 열지 않습니다. 폴더 영상 목록 구성과 수동 버튼은 계속 사용할 수 있고 설정은 저장됩니다.
- 일반 설정의 Windows 기본 앱 설정 버튼. ZM을 파일 연결 후보로 등록한 뒤 Windows 설정에서 연결할 파일 형식을 선택합니다. 설치 시에도 후보를 등록합니다.
- 다중 오디오 트랙 순환 선택.
- 외부 SRT/ASS/SSA/WebVTT와 내장 텍스트 자막의 libass 렌더링, ON/OFF, 크기/글꼴 덮어쓰기, ±100 ms 동기화.
- 동일 이름과 선호 언어 접미사 자막 자동 검색: Movie.srt, Movie.ko.srt, Movie.kor.srt 등.
- 다크/라이트, 한국어·English·日本語·简体中文·繁體中文·國漢文混用體의 즉시 전환.
- 둥근 나눔스퀘어라운드 UI 글꼴, 모서리가 둥근 버튼, 창 너비에 맞춘 컨트롤 배치. 영상과 시간/탐색/버튼 영역을 분리합니다.
- 왼쪽 메뉴와 스크롤 가능한 설정 화면: 일반 / 모양 / 성능 / 자막 / 단축키 / 정보. 모양에서 테마와 둥근 글꼴을 선택합니다.
- 전체화면 진입 시 상·하단 UI와 폴더 목록을 함께 숨깁니다. 마우스 이동·가장자리 클릭으로 다시 표시하지 않습니다. 전체화면에서 Tab으로 UI 표시/숨김을 전환합니다. 일시정지 중에도 동작하며, 모양 설정에서 숨김을 끌 수 있습니다.
- 창 이동·크기 조절 중에도 UI 스레드의 Windows 타이머에서 영상을 갱신합니다. 모양 설정에서 계속 표시를 켜거나 끌 수 있습니다.
- 정보 설정의 후원 버튼으로 `https://buymeacoffee.com/zernia`를 기본 브라우저에서 엽니다.
- 시작 시 업데이트 확인과 새 설치기 자동 다운로드. 일반 설정에서 각각 ON/OFF, 정보 화면에서 수동 확인·다운로드·설치가 가능합니다. GitHub 릴리스의 SHA-256으로 검증한 설치기만 설치 버튼에 연결하며, 설치 실행은 버튼을 누른 뒤 진행합니다. [업데이트 및 릴리스 절차](docs/releasing.md).
- 사용자 제공 `icon.png` 기반 Windows 실행 파일/창/작업표시줄 아이콘. `scripts/create-icon.ps1`로 ICO 리소스를 다시 만들 수 있습니다.
- 사용자 지정 단축키, 검색, 충돌 확인 후 교체/취소, 개별/전체 복원과 저장.
- D3D11VA 하드웨어 디코딩 및 실패 시 소프트웨어 대체. 실제 하드웨어 사용 시 하단에 GPU 표시.
- Unicode 파일 경로, DPI-aware 창, 오류 표시와 잘못된 설정 항목의 기본값 복구.
- 볼륨/테마/언어/자막/가속 옵션과 단축키 저장. 사용자별 SDL 설정 폴더의 Zernia/ZM 아래에 저장합니다.

## 기본 조작

| 키 | 기능 |
| --- | --- |
| Space | 재생/일시정지 |
| ← / →, Ctrl+← / → | ±5초, ±30초 |
| ↑ / ↓, 휠 | 볼륨 |
| F, Esc | 전체화면 전환, 설정 닫기/전체화면 종료 |
| M | 음소거 |
| S, Ctrl+S, J | 자막 ON/OFF, 외부 자막 열기, 다음 내장 자막 |
| A | 다음 오디오 트랙 |
| P, PageUp / PageDown | 재생목록, 이전/다음 파일 |
| Ctrl+O, Ctrl+, | 파일 열기, 설정 |

재생목록: 클릭으로 선택, 더블클릭으로 재생, Delete로 삭제, Shift+↑/↓로 순서 이동합니다.

설정 → 단축키: 행을 클릭하고 새 키를 누릅니다. 충돌 시 Enter로 교체하거나 Esc로 취소합니다. 검색은 페이지에서 입력하며 휠 또는 오른쪽 스크롤바로 스크롤합니다. Win 키 조합은 OS용으로 남겨둡니다. 설정의 언어/테마 항목은 드롭다운으로 선택합니다.

## 빌드와 배포

Visual Studio C/C++ x64 도구, Windows SDK와 포함된 CMake/Ninja가 필요합니다.

```powershell
.\scripts\setup-deps.ps1
.\scripts\build.ps1 -Configuration Release
.\scripts\build.ps1 -Configuration Debug
.\scripts\package.ps1
.\scripts\build-installer.ps1
```

결과는 `build/Release/ZM.exe`, `build/Debug/ZM.exe`입니다. 의존성 설치는 FFmpeg n9.0.2-22, SDL2 2.32.10, SDL2_ttf 2.24.0의 고정 URL과 SHA256을 사용합니다. [라이선스와 출처](THIRD_PARTY.md)를 참고하세요.

빌드가 CTest를 실행합니다. test-media/sample.mp4와 multiaudio.mkv가 존재하면 실제 재생 회귀 테스트도 등록합니다. `ZM.exe --smoke 3 "파일 경로"`는 3초 후 검사 결과를 종료 코드로 반환하고, `--capture 경로.bmp`로 검증 화면을 저장합니다.

설치기 빌드에는 Inno Setup 6 컴파일러가 필요합니다. 기본 설치 위치 또는 `third_party/inno/ISCC.exe`를 자동으로 찾습니다. 설치기는 한국어/영어/일본어로 표시할 수 있습니다.

## 후속 기능과 알려진 제한

- 재생 속도, 프레임 이동, A/B 반복, 재생 위치/최근 파일 기억, 폴더 직접 선택 및 하위 폴더 탐색.
- 시스템 테마, 상세 자막 글꼴/색상/외곽선/그림자/위치 설정, 자막 문자 인코딩 수동 선택. 현재 스타일 덮어쓰기는 Malgun Gothic와 기본 외곽선/그림자/하단 위치입니다.
- 출력 장치/오디오 동기화 설정, 상세 미디어 정보, 화면 비율/줌, 사용자용 PNG/JPEG 캡처.
- 독립 demux/video/audio 스레드, GPU zero-copy, HDR/tone mapping, NVDEC/QSV/DXVA2 개별 선택. 현재 D3D11VA가 해당 GPU의 하드웨어를 사용합니다.
- 업데이트, 완전한 UI 접근성과 키보드 포커스 이동.
- Linux는 미검증이며 파일 선택 창은 Windows 전용입니다. 8K/장시간/긴 경로 및 모든 코덱/장치 조합도 미검증입니다.
- 내장 자막 그래프는 전체 자막을 미리 읽을 수 있어 큰 파일에서 초기 지연과 메모리 증가가 가능합니다. 비트맵 자막은 미검증입니다.
- GPU 프레임을 CPU로 전송해 출력하므로 zero-copy가 아닙니다. 큐에 들어간 오디오 때문에 볼륨/음소거 적용이 최대 약 0.5초 늦을 수 있습니다.

후속 개발은 기존 기능과 API를 유지하며 위 요구사항을 이어갑니다.
